# 👋 How to Use This Vault

**Back to:** [[00 - Onboarding Roadmap]]

> [!NOTE] Read This First
> This guide explains how to navigate and use the **Data Engineering 101** onboarding vault effectively. Spend 5 minutes here before starting D1.

---

## 🗺️ Where to Start

1. Open **[[00 - Onboarding Roadmap]]** — your master progress tracker
2. Work through domains **D1 → D6** in order
3. Complete the **Checkpoint** at the end of each domain before moving to the next
4. Domain **D7** is optional — tackle it after D6 if you're supporting AI/LLM workloads

---

## 📋 Tracking Your Progress

Each domain note has a `status` field in its frontmatter. Update it as you go:

| Status | Meaning |
|--------|---------|
| `not-started` | Haven't begun yet |
| `in-progress` | Currently working through it |
| `done` | Content consumed, ready for checkpoint |
| `needs-review` | Done, but want to revisit |

**To update:** Edit the frontmatter `status:` field in any note.

Each domain also has a `## ✅ Practice Checklist` — check off items as you complete them.

---

## ✅ How Checkpoints Work

1. Complete all practice checklist items in the domain note
2. Open the checkpoint note (e.g., `[[Checkpoints/CP1 - Tooling & Environment Ready]]`)
3. Self-assess against each criterion — check the boxes you can honestly tick
4. **Book a review with your mentor** — they verify and sign off
5. Only after mentor sign-off: update checkpoint `status: passed` and move to the next domain

> [!WARNING] Don't Skip Checkpoints
> Checkpoints gate progression for a reason. If you can't pass CP2 SQL criteria, D3+ content won't stick.

## 🕐 Rough Time Estimates

| Domain | Estimated Time | Notes |
|--------|---------------|-------|
| D1 Foundations | 1–2 weeks | Lighter for analysts — most tools are new |
| D2 SQL & Modeling | 1–2 weeks | Deepen existing SQL knowledge |
| D3 Storage & Formats | 1 week | Mostly conceptual |
| D4 Batch & ETL | 2–3 weeks | Hands-on dbt project required for CP4 |
| D5 Stream Processing | 1–2 weeks | Conceptual first; hands-on is optional at intern level |
| D6 Cloud & Orchestration | 2 weeks | Requires running actual tools (Docker, Airflow) |
| D7 AI-Ready DE *(optional)* | 1–2 weeks | After CP6 only |

Total: **~3 months** at a comfortable pace (5–10 hrs/week)

## 📚 How Notes Are Structured

Every domain note (D1–D6) follows the same pattern:

```
[!NOTE] callout       ← What you'll learn
## N.M — Subdomain    ← Content section
## ✅ Practice Checklist
## 📚 Domain References
## 🃏 Quick-Reference Flash Cards
Checkpoint link + navigation
```

---

## 🆘 Getting Help

- **Stuck on a concept?** Check the `## 📚 Domain References` section in the relevant domain note
- **Ready for checkpoint review?** Contact your onboarding mentor
- **Found an error or want to improve a note?** Flag it with `status: needs-review` in the frontmatter
