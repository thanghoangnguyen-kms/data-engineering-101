## ✅ Pass Criteria

- [ ] Write a SQL query using at least 2 window functions (`ROW_NUMBER`, `RANK`, `LAG`, `LEAD`, or `SUM OVER`)
- [ ] Write a query using a CTE that is referenced more than once
- [ ] Write DDL to create a table with appropriate data types, primary key, and at least one foreign key
- [ ] Explain when to use `DECIMAL` vs `FLOAT` for numeric data, and why it matters for financial data
- [ ] Demonstrate the difference between `TIMESTAMP` and `TIMESTAMPTZ` — and explain when timezone matters
- [ ] Write a `CREATE VIEW` or stored procedure that encapsulates a reusable transformation
- [ ] Explain the difference between `WHERE` and `HAVING` with an example
- [ ] Identify and fix a slow query using `EXPLAIN` or query plan analysis
- [ ] Design a simple star schema (1 fact table + 2 dimension tables) for a given business scenario
