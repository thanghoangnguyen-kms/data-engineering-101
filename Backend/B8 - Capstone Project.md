## ✅ Project Deliverables

- [ ] GitHub repository with clean commit history
- [ ] REST API with at least 5 endpoints (CRUD + auth-protected)
- [ ] JWT or OAuth authentication implemented
- [ ] PostgreSQL database with at least 2 related tables and migrations
- [ ] At least one background job (e.g., email, notification)
- [ ] Full test suite with ≥80% coverage
- [ ] Dockerised with docker-compose.yml that starts the full stack
- [ ] README with setup instructions, API docs link, and architecture diagram
